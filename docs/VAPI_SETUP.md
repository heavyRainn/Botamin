# Настройка Vapi и Google Calendar для Botamin

Пошаговая инструкция для первого запуска голосового консультанта Botamin. Предполагается, что у вас уже развёрнут сайт из этого репозитория и есть аккаунт [Vapi](https://vapi.ai).

## Создание агента

1. Откройте [Vapi Dashboard](https://dashboard.vapi.ai).
2. Перейдите в раздел **Assistants**.
3. Нажмите **Create Assistant** и выберите пустой шаблон (Blank Assistant).
4. Назовите ассистента: `Botamin Voice Consultant`.
5. Установите язык: **Russian (ru)**.
6. Выберите **женский голос** с хорошей поддержкой русского языка. В Dashboard откройте список доступных голосов, прослушайте несколько вариантов и выберите спокойный разговорный голос. Не используйте идентификаторы из документации — только те, что доступны в вашем кабинете.
7. Выберите **быструю модель** с небольшой задержкой (low-latency). Конкретную модель выберите из актуального списка в Dashboard.
8. Откройте файл [`VAPI_SYSTEM_PROMPT.md`](./VAPI_SYSTEM_PROMPT.md) в этом репозитории и **полностью скопируйте** системный промпт в поле **System Prompt** ассистента.
9. Установите **первое сообщение** (First Message):

   ```text
   Добрый день! Я голосовой консультант Botamin. Подскажите, чем занимается ваша компания?
   ```

10. Сохраните и **опубликуйте** ассистента (Publish).
11. Скопируйте **Assistant ID** (формат `asst_...`).
12. Откройте **Vapi Dashboard → API Keys** и скопируйте **Public API Key** (формат `pk_...`). Используйте именно публичный ключ — он безопасен для клиентского виджета.
13. Создайте файл `.env.local` в корне проекта (рядом с `package.json`) и добавьте:

    ```env
    NEXT_PUBLIC_VAPI_PUBLIC_KEY=ваш_public_key
    NEXT_PUBLIC_VAPI_ASSISTANT_ID=ваш_assistant_id
    ```

14. Перезапустите локальный сервер (`npm run dev`), если он уже был запущен.

## Google Calendar

Используется **прямая интеграция Vapi с Google Calendar**. Cal.com и сторонние сервисы бронирования не нужны.

### Подготовка календаря

1. Откройте [Google Calendar](https://calendar.google.com).
2. Создайте **дополнительный календарь** (не обязательно primary):

   ```text
   Botamin Demo Meetings
   ```

3. Откройте настройки этого календаря и установите часовой пояс:

   ```text
   Europe/Moscow
   ```

4. Скопируйте **Calendar ID** (в настройках календаря → «Integrate calendar» → Calendar ID). Если используете основной календарь, ID может быть вашим email.

### Подключение в Vapi

1. В Vapi Dashboard откройте: **Integrations → Tools Provider → Google Calendar**.
2. Нажмите **Connect** и авторизуйте Google-аккаунт, у которого есть доступ к календарю `Botamin Demo Meetings`.
3. Перейдите в раздел **Tools** (или **Tools** внутри ассистента).
4. Создайте инструмент **Google Calendar Check Availability Tool**.
5. Назовите его:

   ```text
   check_calendar_availability
   ```

6. В описание инструмента вставьте:

   ```text
   Проверяет занятость Google Calendar для конкретного интервала. Используй перед каждым предложением слота и повторно непосредственно перед созданием события. Проверяй только будни, не раньше следующего рабочего дня, с началом встречи от 09:00 до 17:00 включительно по часовому поясу Europe/Moscow. Встреча длится 20 минут. Не сообщай пользователю, что слот свободен, пока инструмент не вернул успешный результат.
   ```

7. Укажите **calendarId** созданного календаря (если не primary).
8. Создайте инструмент **Google Calendar Create Event Tool**.
9. Назовите его:

   ```text
   create_calendar_event
   ```

10. В описание инструмента вставьте:

    ```text
    Создаёт 20-минутную встречу в Google Calendar. Используй только после получения телефона или Telegram, подтверждённой рабочей почты и окончательно выбранного свободного слота. Перед вызовом повторно проверь слот через check_calendar_availability. Добавь рабочую почту в attendees, контакт и отрасль в описание, передай timeZone Europe/Moscow. Никогда не вызывай инструмент без обязательных данных.
    ```

11. Укажите тот же **calendarId**.
12. Добавьте **оба инструмента** в ассистента `Botamin Voice Consultant` (в разделе Tools ассистента).
13. Опубликуйте изменения ассистента.

### Важно про время и часовой пояс

Google Calendar Tool работает с датами в формате **ISO 8601**. При каждом вызове инструментов проверки и создания события **всегда передавайте**:

```text
timeZone: Europe/Moscow
```

Не полагайтесь на часовой пояс браузера пользователя — все слоты рассчитываются по Москве.

## Первое сообщение агента

Используйте точный текст:

```text
Добрый день! Я голосовой консультант Botamin. Подскажите, чем занимается ваша компания?
```

## Рекомендуемые настройки ассистента

| Параметр | Рекомендация |
|----------|--------------|
| Язык | Русский |
| Голос | Женский, спокойный, разговорный (выбрать в Dashboard после прослушивания) |
| Скорость речи | Обычная, без ускорения |
| Длина ответов | Короткие реплики |
| Перебивание (Interruption) | Разрешить |
| Чувствительность перебивания | Средняя |
| Задержка ответа | Минимально комфортная (не добавляйте искусственных пауз) |
| Длинные монологи | Запрещены — следуйте системному промпту |

## Проверка после настройки

1. Откройте локальный сайт (`http://localhost:3000`).
2. Убедитесь, что в правом нижнем углу появился виджет «Консультант Botamin».
3. Нажмите **Начать разговор** и разрешите доступ к микрофону.
4. Пройдите сценарий из [`VAPI_TEST_SCENARIOS.md`](./VAPI_TEST_SCENARIOS.md) — минимум сценарий №1 (успешная запись).
5. Проверьте, что событие появилось в Google Calendar `Botamin Demo Meetings`.

## Безопасность

**Никогда не добавляйте в frontend или в репозиторий:**

- `VAPI_PRIVATE_KEY`
- `VAPI_API_KEY` (приватный)
- `GOOGLE_PRIVATE_KEY`
- `GOOGLE_CLIENT_SECRET`

На сайте используются только `NEXT_PUBLIC_VAPI_PUBLIC_KEY` и `NEXT_PUBLIC_VAPI_ASSISTANT_ID`.
